# Gateway Operator SOP

## Health checks
1. Confirm the gateway device shows online on the Virtuoso dashboard.
2. Check last activity time and connectivity readings.
3. Verify downstream DG devices are still publishing live values.

## If gateway offline
1. Check power and network path.
2. Validate MQTT/HTTP connectivity settings with an admin.
3. Confirm certificates/credentials without sharing secrets in chat.
4. After recovery, confirm DG SET1 live readings resume.
